# PickMe

Simple Decision Helper App

PickMe is a small open-source Flutter app for quick random decisions. Add a few options, tap **Pick Me**, and let the app choose one result.

## Features

- Random Decision Picker
- Multiple Options
- Decision History
- Material Design UI
