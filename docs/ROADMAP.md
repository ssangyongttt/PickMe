# Roadmap

PickMe intentionally starts small. Future features should keep the app simple, privacy-friendly, and easy to maintain.

## Planned Ideas

- Wheel Mode
- Team Decision Mode
- Tournament Mode

## Potential Improvements

- Screenshot assets for the README
- Option group templates
- Local-only history clear action
- Small accessibility improvements

## Not Planned

- User accounts
- Ads
- Payments
- Analytics
- Backend server
