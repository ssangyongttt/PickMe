# Project Overview

## Summary

PickMe is a simple Flutter decision helper app. It is designed as an independent public portfolio project and does not connect to any production service, backend, analytics platform, ad network, payment service, or user account system.

## Problem

Small daily decisions can be slow when every option feels similar. PickMe helps users make lightweight random choices such as lunch menus, weekend plans, drinks, or travel ideas.

## Core Flow

1. Add two or more options.
2. Tap the **Pick Me** button.
3. Review the selected result.
4. Check recent results when needed.

## Included Features

- Text option input
- Empty input guard
- Maximum 20 options
- Removable option cards
- Clear all options action
- Random result picker
- Result highlight animation
- Quick example chips
- Recent result history up to 5 items
- System light and dark theme support

## Non-Goals

- Login
- Signup
- Ads
- Payments
- Server APIs
- Firebase
- Analytics
- Personal data collection

## Repository Goal

This repository is built to be easy to review on GitHub: clear README, concise documentation, simple app structure, and basic Flutter verification commands.
