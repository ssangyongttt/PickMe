# Privacy

PickMe is designed to be privacy-friendly by default.

## Data Collection

PickMe does not collect personal information.

## Accounts

No account is required.

## Analytics

PickMe does not use analytics tools.

## Ads

PickMe does not show ads.

## Payments

PickMe does not include payments or in-app purchases.

## Local Storage

PickMe stores only recent decision results locally on the user's device through Flutter shared preferences. This data is not sent to any server.

## Network

PickMe does not require a backend server or external API.
